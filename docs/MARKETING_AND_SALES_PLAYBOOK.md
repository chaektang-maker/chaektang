# คู่มือการขายและการตลาดครบวงจร — เว็บไซต์ "แจกตัง" (Chaektang)

เอกสารชุดนี้ออกแบบมาเพื่อให้ทีมงานนำไปใช้ **ก๊อปปี้ข้อความส่งให้ลูกค้า/โพสต์โปรโมทได้ทันที** แบ่งออกเป็น 3 หมวดหลัก:
1. **B2B Sponsorship:** คู่มือและสคริปต์ขายพื้นที่โปรโมทให้ "สำนักหวย / เพจใบ้หวย / อาจารย์ดัง"
2. **Website Traffic:** แผนโปรโมทเว็บไซต์และแคปชั่นดึงคนเข้าเว็บ (Facebook, TikTok, LINE)
3. **B2C VIP Sales:** แคปชั่นและกลยุทธ์กระตุ้นให้คนทั่วไปสมัครสมาชิก VIP (99฿ / 179฿ / 450฿)

## ส่วนที่ 1: คู่มือขายพื้นที่โปรโมทให้ "สำนักหวย / เพจหวย" (B2B Sponsorship)

### 1.1 จุดขายที่ทำให้เจ้าของสำนักหวยอยากจ่ายเงิน (Value Proposition)
เวลาคุยกับเจ้าของสำนักหวยหรือแอดมินเพจใบ้หวย สิ่งที่เขาต้องการมากที่สุดคือ **"ลูกศิษย์เพิ่ม / คนแอด LINE เพิ่ม / ความน่าเชื่อถือ"** ซึ่งระบบของเว็บแจกตังตอบโจทย์ครบทุกข้อ:

1. **ได้ขึ้นหน้าแรกของเว็บ (`/`):** โซนพิเศษ *"⭐ เลขเด็ดสำนักแนะนำประจำงวดนี้"* กรอบสีทองโดดเด่น อยู่ใต้กล่องตรวจหวยที่คนเข้าเยอะที่สุด
2. **ล็อกตำแหน่งแถวบนสุดของหน้า `/lucky-numbers`:** ไม่ว่าคนเข้าเว็บจะกดเรียงตาม "มาแรง" หรือ "อัปเดตล่าสุด" การ์ดของสำนักสปอนเซอร์จะ **ถูกปักหมุดอยู่บนสุดเสมอ**
3. **ป้ายรับรอง `⭐ สำนักแนะนำ` + กรอบทอง:** สร้างความน่าเชื่อถือเหนือกว่าสำนักทั่วไปในตาราง
4. **เปิดเลข 100% ให้ทุกคนเห็นฟรี (ไม่ติดล็อก VIP):** ในขณะที่สำนักดังอื่นๆ ในเว็บถูกระบบล็อกเลข `🔒 VIP` แต่สำนักสปอนเซอร์จะเปิดเลข 2 ตัว, 3 ตัว และเลขวิ่งให้คนเห็นครบ 100% ทำให้คนแห่มาดูเลขของสำนักสปอนเซอร์มากที่สุด
5. **มีพื้นที่ใส่คำโปรย / ช่องทางติดต่อ (`Description`):** ใส่ชื่อเพจ, ชื่อกลุ่ม หรือ `Line ID: @...` ใต้ชื่อสำนักในการ์ดได้โดยตรง ดึงคนเข้ากลุ่มของสำนักได้ทันที

### 1.3 สคริปต์ทักแชทเสนอขายสำนักหวย (Copy & Paste)

#### รูปแบบที่ 1: ทักไปเชิญสำนักขึ้นเว็บฟรี 1 งวดก่อน แล้วค่อยปิดการขายปักหมุด (ได้ผลดีที่สุดสำหรับเว็บเปิดใหม่)
```text
สวัสดีครับแอดมินเพจ [ชื่อสำนัก/ชื่อเพจ] 🙏
ผมติดต่อจากเว็บไซต์ "แจกตัง" (ศูนย์รวมแนวทางเลขเด็ดและสถิติความแม่นยำสำนักดัง) ครับ

ตอนนี้ทางเว็บกำลังรวบรวมแนวทางเลขเด็ดจากสำนักที่น่าเชื่อถือประจำงวดนี้ ซึ่งเราเห็นว่าแนวทางของ [ชื่อสำนัก] มีแฟนคลับติดตามเยอะและตัวเลขน่าสนใจมากครับ

ทางทีมงานเลยขออนุญาตนำชื่อสำนัก [ชื่อสำนัก] ขึ้นแสดงในตารางเลขเด็ดของเว็บให้ "ฟรี" ไม่มีค่าใช้จ่ายครับ โดยแอดมินสามารถส่งแนวทางเลข 2 ตัว / 3 ตัว / เลขวิ่ง ของงวดนี้มาให้ทีมงานลงให้ได้เลยครับ

และพิเศษสำหรับงวดนี้! หากทางสำนักต้องการให้คนเห็นเลขเยอะขึ้นและมีคนแอดเข้ากลุ่ม/เพจมากขึ้น ตอนนี้เรามีโซนพิเศษ "⭐ สำนักแนะนำประจำงวด (ปักหมุดกรอบทองหน้าแรก + แถวบนสุด + ใส่ช่องทางติดต่อ/Line ID บนการ์ดได้)" รับจำกัดเพียง 3 สำนักต่องวด โปรเปิดตัวเพียงงวดละ 490 บาท (จากปกติ 1,000 บาท)

สนใจดูตัวอย่างการ์ดปักหมุดกรอบทองบนหน้าเว็บก่อนไหมครับ เดี๋ยวผมแคปหน้าจอส่งให้ดูครับ 😊
```

#### รูปแบบที่ 2: ทักขายแพ็กเกจปักหมุดตรงๆ (สำหรับสำนักที่มีรายชื่ออยู่ในเว็บเราแล้ว)
```text
สวัสดีครับแอดมิน [ชื่อสำนัก] 🙏
ติดต่อจากเว็บไซต์ "แจกตัง" ครับ ตอนนี้ทางเราได้อัปเดตแนวทางเลขเด็ดของ [ชื่อสำนัก] ขึ้นบนระบบเรียบร้อยแล้วนะครับ มีผู้ชมเข้ามาดูและกดโหวตให้ความแม่นยำต่อเนื่องเลยครับ

พอดีงวดนี้ทางเว็บเปิดพื้นที่พิเศษ "⭐ สำนักแนะนำประจำงวด" (จำกัดแค่ 3 สำนักต่องวด) ซึ่งสำนักที่ได้ขึ้นโซนนี้จะได้สิทธิ์พิเศษ 4 ข้อครับ:
1. การ์ดเลขเด็ดของสำนักจะถูกดันขึ้น "หน้าแรกของเว็บ" และ "แถวบนสุด" ของหน้าเลขเด็ดเสมอ
2. ตกแต่งกรอบสีทอง + ป้ายรับรอง "⭐ สำนักแนะนำ" เด่นกว่าสำนักทั่วไป
3. เปิดโชว์เลข 2 ตัว / 3 ตัว ให้คนเข้าเว็บทุกคนเห็นครบ 100% (ในขณะที่สำนักดังอื่นๆ จะถูกล็อกไว้ให้เฉพาะสมาชิก VIP)
4. สามารถใส่ข้อความโปรโมทเพจ หรือ Line ID ไว้ใต้ชื่อสำนักบนการ์ดได้โดยตรง

โปรโมชั่นพิเศษช่วงนี้:
- 1 งวด (15 วัน) เพียง 490 บาท
- 2 งวด (1 เดือน) เพียง 890 บาท (ประหยัดกว่าเดิม)

หากแอดมินสนใจจองสิทธิ์ 1 ใน 3 ที่นั่งของงวดนี้ แจ้งข้อความคำโปรย/Line ID ที่อยากให้ขึ้นบนการ์ดได้เลยครับ เดี๋ยวทีมงานเปิดระบบปักหมุดกรอบทองให้ทันทีครับ!
```

## ส่วนที่ 2: คู่มือโปรโมทเว็บไซต์ให้คนเข้าเยอะๆ (Website Traffic Playbook)

| ช่วงเวลา | พฤติกรรมคนเล่นหวย | สิ่งที่ต้องโพสต์โปรโมทเว็บ | หน้าเว็บที่ใช้แปะลิงก์ |
| :--- | :--- | :--- | :--- |
| **ช่วงต้นงวด**<br>*(หลังหวยออก 1–5 วัน)* | เช็กว่าสำนักไหนแม่นงวดที่แล้ว / หาสำนักที่เข้าติดกันหลายงวด | โพสต์สรุป **"ตารางคะแนนสำนักแม่นยำ / สำนักที่เข้า 3 งวดติด"** | `/accuracy-ranking` หรือ `/leaderboard` |

| **โค้งสุดท้าย**<br>*(ก่อนหวยออก 1–3 วัน)* | รีบหาเลข 2 ตัว / 3 ตัวไปซื้อก่อนอั้น | โพสต์กระตุ้น **"10 อันดับเลขมาแรงชนกันทุกสำนัก! ดูด่วนก่อนอั้น"** | `/lucky-numbers` |
| **วันหวยออก**<br>*(วันที่ 1 และ 16 เวลา 14:00–17:00)* | ตรวจหวย / เช็กว่าสำนักไหนเข้าบ้าง | โพสต์ลิงก์ **"ตรวจหวยกรอกเลขรู้ผลทันที + เช็กผลสำนักไหนแตกบ้างงวดนี้"** | หน้าแรก `/` |

### 2.2 ตัวอย่างแคปชั่นโปรโมทเว็บ (สำหรับโพสต์ลงกลุ่มหวย Facebook / TikTok / X)

✅ มีตารางสถิติย้อนหลังให้ดูจริงว่าสำนักไหนเข้ากี่งวดติด (ไม่มโน!)

สำนักไหนของจริง สำนักไหนเข้า 3 งวดติด ระบบเว็บ "แจกตัง" คำนวณเทียบกับผลกองสลากให้เห็นชัดๆ งวดต่องวด!

## ส่วนที่ 3: คู่มือโปรโมทให้คนสมัครสมาชิก VIP (B2C VIP Conversion)

### 3.1 กลไกของระบบที่ช่วยปิดการขาย VIP อัตโนมัติ
ในหน้า `/lucky-numbers` ระบบได้วาง **"กับดักความอยากรู้ (Curiosity Gap)"** เอาไว้ 2 จุดสำคัญ:
1. **อันดับ 1 เลขเด็ดมาแรงชนกันทุกสำนัก:** อันดับ 2–10 เปิดให้เห็นฟรี แต่ **อันดับ 1 ที่ชนกันเยอะที่สุดถูกล็อก `🔒 VIP`**
2. **สำนักที่เข้า 3 งวดติด + สำนักยอดนิยมอันดับ 1 ของงวด:** เปิดให้เห็นเฉพาะเลขวิ่ง แต่ **เลขเจาะ 2 ตัว และ 3 ตัว ถูกล็อก `🔒 VIP`**

---

### 3.3 แคปชั่นและสคริปต์เชิญชวนสมัคร VIP (Copy & Paste)

#### แคปชั่นที่ 1: ขยี้จุด "เลขมาแรงอันดับ 1 + สำนักเข้า 3 งวดติด" (โพสต์ก่อนหวยออก 1–5 วัน)

## ส่วนที่ 4: เช็กลิสต์เตรียมความพร้อมก่อนเริ่มออกไปขายจริง (Action Checklist)
